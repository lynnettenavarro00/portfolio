# Lynnette Navarro · Tiny — Portfolio

Portfolio web de Lynnette Navarro ("Tiny"): filmmaker, fotógrafa, 1AC y 2AC en Madrid.

La web empieza con un sobre lacrado. Al abrirlo, la carta sale, se despliega y da paso a los folios con su trabajo: sobre mí, content creator, on set, foto fija y contacto.

- `index.html`: toda la web (HTML, CSS y JS sin dependencias de build).
- `assets/web/`: fotos y vídeos optimizados para web.
- `assets/hd/`: versiones en alta calidad que se cargan bajo demanda con el botón «HD».

Para verla en local basta con servir la carpeta, por ejemplo con `npx serve .`. Es una web estática, así que se puede publicar tal cual con GitHub Pages.
